## task-started

当客户端发送 `run-task` 指令后，服务端返回 `task-started` 事件，标志任务已成功开启。只有在接收到该事件后，客户端才能继续发送后续指令。

<table bordertype="no-border"><colgroup><col style="width:57.54%"><col style="width:42.46%"></colgroup><tbody><tr><td><p><strong>header.task_id</strong><code>string</code></p><p>客户端生成的任务 ID。</p><p><strong>header.event</strong><code>string</code></p><p>事件类型，固定为 <code>task-started</code>。</p><p><strong>payload</strong><code>object</code></p><p>无内容，为空对象。</p></td><td><pre data-tag="codeblock" id="code-block" outputclass="language-json" code-type="xCode" class="pre codeblock language-json"><code>{
  "header": {
    "task_id": "2bf83b9a-baeb-4fda-8d9a-xxxxxxxxxxxx",
    "event": "task-started",
    "attributes": {}
  },
  "payload": {}
}
</code></pre></td></tr></tbody></table>

## task-finished

服务端返回 `task-finished` 事件，标志任务已结束。客户端可以关闭 WebSocket 连接或复用连接开启新任务。

<table bordertype="no-border"><colgroup><col style="width:57.54%"><col style="width:42.46%"></colgroup><tbody><tr><td><p><strong>header.task_id</strong><code>string</code></p><p>客户端生成的任务 ID。</p><p><strong>header.event</strong><code>string</code></p><p>事件类型，固定为 <code>task-finished</code>。</p><p><strong>payload.usage.characters</strong><code>integer</code></p><p>截止当前累计的计费字符数。</p></td><td><pre data-tag="codeblock" id="code-block-2" outputclass="language-json" code-type="xCode" class="pre codeblock language-json"><code>{

    "event": "task-finished",
    "attributes": {
      "request_uuid": "0a9dba9e-d3a6-45a4-be6d-xxxxxxxxxxxx"
    }
  },
  "payload": {
    "usage": {

  }

</code></pre></td></tr></tbody></table>

## task-failed

当任务失败时，服务端返回 `task-failed` 事件。客户端需要关闭 WebSocket 连接并处理错误。
