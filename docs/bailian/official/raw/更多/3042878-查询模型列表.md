调用 GET /api/v1/models 接口查询百炼平台上可用的模型列表，支持按模型作者、模态类型、模型能力、部署模式等条件筛选，并获取模型的定价和上下文长度等信息。

## 前提条件

已创建 API Key 并配置为环境变量 `DASHSCOPE_API_KEY`。配置方法请参见[配置API Key到环境变量](https://help.aliyun.com/zh/model-studio/configure-api-key-through-environment-variables)。

## 请求说明

-   **HTTP 方法**：GET
    
-   **请求地址**
    
    > 调用时请将 `{WorkspaceId}` 替换为您的业务空间 ID。
    
    | 地域 | Endpoint |
    | --- | --- |
    | 华北2（北京） | https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/models |
    | 新加坡 | https://dashscope-intl.aliyuncs.com/api/v1/models |
    | 中国香港 | https://cn-hongkong.dashscope.aliyuncs.com/api/v1/models |
    | 德国（法兰克福） | https://{WorkspaceId}.eu-central-1.maas.aliyuncs.com/api/v1/models |
    | 日本（东京） | https://{WorkspaceId}.ap-northeast-1.maas.aliyuncs.com/api/v1/models |
    | 美国（弗吉尼亚） | https://dashscope-us.aliyuncs.com/api/v1/models |
    
-   **认证方式**
    
    在请求 Header 中设置 `Authorization: Bearer {API_KEY}`。
    

## 请求参数

所有参数均通过 Query String 传递。

| 参数 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| providers | Array[String] | 否 | 按模型作者筛选。可选值：qwen：Qwendeepseek：DeepSeekzhipu-ai：Zhipu AIwan：Wanmoonshot-ai：Moonshot AImini-max：MiniMaxkling：Kling AIvidu：Vidupixverse：PixVersexiaomi：小米tripo：Tripohappyhorse：HappyHorseqwen-domain-model：Qwen Domain Model示例：providers=qwen&providers=deepseek |
| inference_providers | Array[String] | 否 | 按推理服务供应商筛选。可选值：aliyun-bailian：阿里云百炼alibaba-cloud-modelstudio：Alibaba Cloud Model Studiosiliconflow：硅基流动moonshot：Kimimini-max：MiniMaxkling：Kling AIvidu：Vidupixverse：PixVersevanchin：快手万擎xiaomi：小米MiMozhipu-ai：Zhipu AItripo：Tripo |
| capabilities | Array[String] | 否 | 按模态类型筛选。可选值：TG：文本生成（Text Generation）Reasoning：深度推理（Advanced Reasoning）VU：视觉理解（Visual Understanding）IG：图像生成（Image Generation）VG：视频生成（Video Generation）ASR：语音识别（Speech Recognition）TTS：语音合成（Text-to-Speech）TR：文本向量（Text Embedding）ME：多模态向量（Multimodal Embedding）Multimodal-Omni：全模态（Omni）Realtime-Omni：实时全模态（Realtime Omni）Realtime-Text-to-Speech：实时语音合成Realtime-ASR：实时语音识别Realtime-Audio-Translate：实时语音翻译示例：capabilities=TG&capabilities=Reasoning |
| features | Array[String] | 否 | 按模型能力筛选。可选值：function-calling：Function Callingstructured-outputs：Structured Outputsweb-search：联网搜索prefix-completion：前缀续写cache：上下文缓存batch：批量推理fine-tuning：模型微调model-experience：模型体验 |
| context_window | Integer | 否 | 按上下文长度筛选，返回上下文长度大于等于该值的模型。示例：20000 |
| service_site | String | 否 | 按部署模式筛选。不传时返回所有部署模式的模型。可选值：global：全球模式international：国际模式（除中国大陆外）asia-pacific-china：中国大陆cn-hongkong：中国香港european-union：欧盟united-states：美国japan：日本 |
| supports | Array[String] | 否 | 按模型支持的应用场景筛选。默认值：inference。可选值：inference：支持推理的模型deploy：支持部署的模型 |
| deployment_methods | Array[String] | 否 | 按部署方式筛选。可选值：ptu：预置吞吐量（Provisioned Throughput Unit） |
| deployment_ptu_service_tiers | Array[String] | 否 | 按 PTU 类型筛选，使用时需同时设置 deployment_methods 包含 ptu。 |
| name | String | 否 | 按模型名称进行模糊搜索。示例：qwen |
| model | String | 否 | 按模型 ID 进行精确查询。示例：qwen3-max |
| language | String | 否 | 返回结果的语言。可选值：zh-CN（中文）、en-US（英文）。 |
| page_no | Integer | 否 | 页码，从 1 开始。默认值：1。 |
| page_size | Integer | 否 | 每页返回的模型数量。默认值：20。 |

## 返回参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| request_id | String | 请求 ID，用于问题排查。 |
| output.total | Number | 符合条件的模型总数。 |
| output.page_no | Number | 当前页码。 |
| output.page_size | Number | 每页条数。 |
| output.models[].model | String | 模型 ID，用于 API 调用时指定模型。 |
| output.models[].name | String | 模型的显示名称。 |
| output.models[].description | String | 模型的功能描述。 |
| output.models[].provider | String | 模型作者，如 qwen。 |
| output.models[].inference_provider | String | 推理服务供应商，如 aliyun-bailian。 |
| output.models[].capabilities | Array[String] | 模型支持的模态类型，取值与请求参数 capabilities 一致。 |
| output.models[].features | Array[String] | 模型支持的能力列表，取值与请求参数 features 一致。 |
| output.models[].published_time | String | 模型发布时间，格式：yyyy-MM-dd HH:mm:ss。可能为 null。 |
| output.models[].inference_metadata | Object | 模型的输入输出模态信息，包含以下字段：request_modality（Array[String]）：输入模态，可选值为 Text、Image、Audio、Video。response_modality（Array[String]）：输出模态，可选值同上。 |
| output.models[].model_info | Object | 模型的上下文长度信息，包含以下字段（值为 null 表示无限制或不适用）：context_window（Integer）：上下文窗口总长度max_input_tokens（Integer）：最大输入 Token 数max_output_tokens（Integer）：最大输出 Token 数max_reasoning_tokens（Integer）：最大推理 Token 数 |
| output.models[].prices | Array[Object] | 模型定价信息。每个元素包含：range_name（String）：分段名称。如无分段计费则为 Default，如有分段则为具体区间（如 32k<Input<=128k）。prices（Array[Object]）：价格列表，每项包含 type（计费项）、price（单价）、price_unit（单位，如"每百万tokens"）、price_name（价格描述，如"输入"）。 |

## 请求示例

**示例一：查询所有文本生成模型**

```curl
curl "https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/models?capabilities=TG&page_no=1&page_size=20" \
    --header "Authorization: Bearer $DASHSCOPE_API_KEY" \
    --header "Content-Type: application/json"
```

**示例二：查询 Qwen 系列的推理模型**

```curl
curl "https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/models?providers=qwen&capabilities=TG&capabilities=Reasoning&page_no=1&page_size=100" \
    --header "Authorization: Bearer $DASHSCOPE_API_KEY" \
    --header "Content-Type: application/json"
```
