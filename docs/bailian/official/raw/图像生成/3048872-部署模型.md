将训练好的图像生成模型发布为在线 API 服务。

## 适用范围

-   **适用地域**：当前模型部署 API **仅在华北2（北京）地域**开放。如您使用其他地域，请通过该地域的百炼控制台完成模型部署操作。
-   **开通账号权限**：若使用[阿里云子账号](/zh/model-studio/permission-management-overview)（[RAM用户](https://help.aliyun.com/zh/ram/user-guide/overview-of-ram-users)），需要为子账号授予模型调用、训练和部署[权限](/zh/model-studio/permission-management-overview)。
-   **配置环境变量**：已成功[获取 API Key](/zh/model-studio/get-api-key)，并[配置到环境变量](/zh/model-studio/get-api-key)。
-   **前提条件**：已完成模型微调训练。请先调用[查询调优任务](/zh/model-studio/create-fine-tuning-job-api)接口，确认任务状态 `status` 为 **SUCCEEDED** 后再进行部署。
